# Accessibility case checklist

Use the repository case-doc template. Include axe WCAG 2 A/AA and 2.1/2.2 A/AA tags where supported; document exact tool coverage. Add manual keyboard order, focus visibility, names, errors, zoom/reflow and assistive-technology checks.

Write the affected WCAG criterion, expected behavior, role, route, browser/device and barrier evidence. Automated scans alone do not certify conformance.
